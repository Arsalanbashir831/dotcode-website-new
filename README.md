# Dotcode landing page

A production-ready landing page starter built with Next.js App Router, TypeScript, Tailwind CSS v3, shadcn/ui conventions, GSAP, and Anime.js.

## Start locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Commands

- `pnpm dev` — development server
- `pnpm build` — production build
- `pnpm typecheck` — TypeScript validation

Brand tokens live in `app/globals.css`. The shadcn configuration is in `components.json`, with the first component at `components/ui/button.tsx`.
